이용약관

MPDF 사이트(이하 “사이트”)는 PDF에 음악을 연결한 파일을 만들고, 열고, 링크로 공유하는 무료 도구입니다. 사이트를 이용하면 아래 내용에 동의한 것으로 봅니다.

1. 서비스 범위

  • 파일 열기·편집·저장은 이용자의 브라우저에서 처리됩니다. ‘링크 만들기’를 선택한 공유용 파일은 서버에 저장됩니다.
  • 공개 링크에는 YouTube·HTTPS 트랙을 사용할 수 있습니다. 내장 음원과 편집용 원본이 포함된 파일은 공개 링크로 업로드할 수 없습니다.
  • YouTube 트랙은 공식 플레이어로 재생되며 YouTube 이용약관을 따릅니다. 외부 음원의 접근·재생 가능 여부는 제공 서비스의 설정에 따라 달라질 수 있습니다.

2. 이용자의 책임

  • 올리거나 공유하는 PDF와 트랙에 대한 권리는 이용자에게 있어야 합니다. 저작권·초상권 등 타인의 권리를 침해하는 파일을 공유하면 안 됩니다.
  • 권리 침해 신고가 접수되면 사이트는 해당 링크를 사전 통지 없이 삭제할 수 있습니다.

3. 공개 링크의 이용 기간

  • 링크는 만든 날부터 90일 동안 이용할 수 있습니다. 만료되면 링크를 통한 파일 제공이 중단됩니다. 이 이용 기간은 저장소에서 실제 삭제되는 시각을 보장하지 않습니다.
  • 링크를 아는 사람은 누구나 파일을 열 수 있습니다. 공개를 원하지 않는 자료는 링크로 올리지 말고, 필요한 파일은 직접 보관하세요.
  • 삭제를 원하면 신고·삭제 요청으로 링크를 알려 주세요.

4. 광고

사이트는 광고로 운영됩니다. 광고는 악보 페이지 위가 아닌 사이트의 정해진 자리에 표시됩니다.

5. 보증하지 않는 것

사이트는 있는 그대로 제공됩니다. 파일 손실, 재생 오류, 링크 만료로 생긴 손해에 대해 책임지지 않습니다.

6. 개인정보와 브라우저 저장

  • 일반 파일 제작·열기에는 로그인이 필요하지 않습니다. 선택적으로 SEETO 계정을 연결하면 Firebase Authentication에서 로그인 상태를 처리합니다.
  • 제작자 등록 시 SEETO의 Firebase 프로젝트에 계정 UID, 완성 PDF의 SHA-256 해시, 발행 ID와 등록 시각을 저장합니다. 이 등록 작업은 악보·음원 파일을 업로드하지 않습니다.
  • 공개 링크 생성 시 서버에 공유용 PDF, 제목과 생성 시각 등 링크 제공 정보가 저장됩니다.
  • 제작기 미리보기는 같은 브라우저의 IndexedDB에 임시 파일을 보관할 수 있습니다. 미리보기 자료의 이용 기간은 최대 1일이며, 만료된 자료는 접근·정리 시 삭제합니다. 브라우저의 사이트 데이터 삭제 기능으로 직접 지울 수도 있습니다. 언어 선택과 로그인 상태도 브라우저에 저장될 수 있습니다.
  • 광고·인증·외부 미디어 제공자가 처리하는 정보는 각 제공자의 정책을 따릅니다.
