Questions

What if the person I send it to has no app?
Send the link from “Create link” and it opens in the browser, music included. If they received the file instead, they can drop it on the viewer.
Does my PDF change?
No. A small playlist file is attached using the PDF standard's own attachment feature. Open it anywhere and it's the original PDF.
Why is the file named .pdf?
Because every app opens that name today. MPDF viewers recognize the file by its attachment, not its name. Use .mpdf only for apps that register it.
Can the music information get lost?
Yes, if the file is re-rendered: “Print to PDF”, screenshots, some compressors and markup tools drop attachments. Sending the file itself keeps it intact.
What about copyright?
YouTube tracks play through YouTube's official player. This site never stores audio, so files with embedded audio must be saved as PDF and sent as files rather than links. Audio you embed must be yours to share.

Open format.
No royalties.

If your app opens PDFs, reading one more attachment makes it MPDF-aware. A three-page spec, an 80-line reference, MIT.
