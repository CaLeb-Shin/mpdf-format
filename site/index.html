Opens everywhere

MPDF is a standard PDF with an attachment. Preview, Acrobat, Chrome, any tablet score app. Apps that don't know MPDF simply see a PDF.

The PDF stays untouched

Nothing is drawn on the pages. The player is one collapsible popup. No watermark, no overlay.

Anyone can make one

No install, no sign-up, one minute. Developers: five lines of code. The spec is open and royalty-free.

어디서나 열린다

MPDF는 첨부파일이 든 표준 PDF입니다. 미리보기, Acrobat, 크롬, 아이패드 악보 앱. 모르는 앱에서는 그냥 PDF로 열립니다.

PDF는 그대로

페이지 위에는 아무것도 그리지 않습니다. 플레이어는 접었다 펼 수 있는 팝업 하나. 워터마크 없음, 오버레이 없음.

Questions

What if the person I send it to has no app?
Send the link from “Create link” and it opens in the browser, music included. If they received the file instead, they can drop it on the viewer.
Does my PDF change?
No. A small playlist file is attached using the PDF standard's own attachment feature. Open it anywhere and it's the original PDF.
Why is the file named .pdf?
Because every app opens that name today. MPDF viewers recognize the file by its attachment, not its name. Use .mpdf only for apps that register it.
Can the music information get lost?
Yes, if the file is re-rendered: “Print to PDF”, screenshots, some compressors and markup tools drop attachments. Sending the file itself keeps it intact.
What about copyright?
YouTube tracks play through YouTube's official player. This site never stores audio, so files with embedded audio must be saved as PDF and sent as files rather than links. Audio you embed must be yours to share.

자주 묻는 것

받는 사람이 앱이 없으면?
"링크 만들기"로 만든 링크를 보내면 브라우저에서 바로 보고 듣습니다. 파일로 받았다면 이 사이트의 뷰어에 놓으면 됩니다.
내 PDF가 바뀌나요?
아니요. PDF 표준의 첨부파일 기능에 재생 목록 하나를 넣을 뿐입니다. 어디서 열어도 원래 PDF 그대로입니다.
파일 이름은 왜 .pdf인가요?
오늘 모든 앱이 여는 이름이기 때문입니다. MPDF 뷰어는 이름이 아니라 첨부로 알아봅니다. .mpdf는 지원 앱용 선택지입니다.
음악 정보가 사라지는 경우가 있나요?
"PDF로 인쇄", 스크린샷, 일부 압축·편집 앱으로 다시 저장하면 첨부가 지워집니다. 파일을 그대로 보내면 문제없습니다.
저작권은요?
유튜브 트랙은 유튜브 공식 플레이어로 재생됩니다. 이 사이트는 음원을 저장하지 않으므로, 음원 파일이 든 파일은 링크가 아니라 PDF로 저장해 보내야 합니다. 직접 넣는 음원 파일의 권리는 만드는 분의 책임입니다.
